**Kolam, read as a graph.**

Turns hand-drawn South Indian *pulli kolam* into graphs, measures symmetry and motifs, checks the single-stroke rule, and generates new designs. Classical CV and a learned detector run side by side.

`Python` · `FastAPI` · `React` · `Docker`
